# Chapter 10 — Future Trends and Best Practices in Front-End Engineering

Surveys the current AI model landscape and closes with best-practice prompting guidance:
context-setting, specificity, and patterns for debugging, code review, and documentation.

## What's in this folder

- `prompting-best-practices.md` — before/after demonstrations of each prompting pattern
  from the chapter (context-setting, specificity vs. vagueness, debugging, code review,
  documentation). This chapter is reference/documentation content rather than a runnable
  project, so there's no app here.

**Note:** this chapter names specific external AI models and vendors (Claude, GPT, etc.).
Since that landscape moves fast, treat the version/model names in the book as a snapshot —
check this repo for updates rather than assuming the book's list is current.
