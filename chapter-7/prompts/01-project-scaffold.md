# Prompt 1  —  Project Scaffold

```
You are an expert React developer. Scaffold a new Vite 8 project named
'novamart-dashboard' with the following configuration:
  - React 19 with TypeScript (strict mode)
  - Tailwind CSS v4 (CSS-first configuration, dark mode via @variant dark (.dark &))
  - D3.js v7
  - React Router v8 for routing (single dashboard route for now)
  - ESLint + Prettier with recommended rules
  - Absolute imports via tsconfig paths (@/components, @/hooks, @/data, @/types)
  - lucide-react for icons

Generate:
  1. package.json with all dependencies
  2. tsconfig.json
  3. vite.config.ts  (use @tailwindcss/vite plugin)
  4. src/app.css     (Tailwind v4 entry file with @import and @variant)
  5. The directory structure as a tree
  6. src/main.tsx and src/App.tsx bootstrapping the router

Do not use Create React App. Use Vite 8.
```
