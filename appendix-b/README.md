# Appendix B — Deployment Options (Vercel • GitHub Pages • Netlify)

Covers deploying front-end apps built in the book to Vercel, GitHub Pages, and Netlify,
including pricing tiers, `vercel.json`/`netlify.toml` configuration, and environment variables.

## What's in this folder
- `vercel/` — sample `vercel.json` and config.
- `github-pages/` — sample GitHub Actions workflow for Pages deployment.
- `netlify/` — sample `netlify.toml`.
