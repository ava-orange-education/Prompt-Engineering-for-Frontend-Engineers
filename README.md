# Prompt Engineering for Frontend Engineers

**AI-Assisted Programming for Front-End Engineering**

Companion code repository for *Prompt Engineering for Frontend Engineers*, published by Orange, AVA®.

## About the book

React.js is the most popular technology for building front-end applications today, and generative AI tools now greatly simplify how those applications are built. This book provides a structured path for front-end engineers to learn AI-assisted coding — from mastering component-based architecture with React to using tools like GitHub Copilot and Claude Code to generate components, debug code, and implement complex features.

Through practical, guided projects — a To-Do app, a responsive dashboard, and a data-driven interface — each built first by hand and then again with AI assistance, readers learn to use AI as a creative and efficient collaborator rather than a black box. The book closes with agentic and multimodal prompting, deployment, and a look at where the field is heading.

**Written for:** front-end developers, full-stack developers working with React in production, JavaScript engineers building interactive UIs, and anyone modernizing a legacy frontend or teaching React who wants to add AI-assisted workflows to their toolkit.

## Why this repo exists

AI tools, model versions, and framework releases move faster than print cycles. Code and prompts shown in the book are a snapshot in time — this repo is the living, updated companion. Clone it any time to get working versions of the examples and prompts, independent of when your copy of the book was printed.

## How to use this repo

Each chapter has its own folder with the prompts, code, or configuration referenced in that chapter. Chapters that pair a "coding it by hand" chapter with a "generating it with AI" chapter (4→5, 6→7, 8→9) are meant to be compared side by side.

```bash
git clone https://github.com/ava-orange-education/Prompt-Engineering-for-Frontend-Engineers.git
cd Prompt-Engineering-for-Frontend-Engineers
```

Open each chapter folder's own `README.md` for setup and run instructions.
