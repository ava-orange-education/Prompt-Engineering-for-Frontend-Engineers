# Svelte 5 runes example

Demonstrates the book's Chapter 2 excerpt "Svelte 5 Runes and Component Syntax" —
`src/lib/Counter.svelte`, using `$state`, `$derived`, `$effect`, and `$props`.

Stack: Vite 8, Svelte 5.

## Run

```
npm install
npm run dev
npm run build
```

## Verified

`npm run build` succeeds. No API changes from the book's snippet were needed — all
four runes are unchanged in Svelte 5.57.
