# Explanation Prompt A — Plain-English Architecture Summary

```
Write a 250-word plain-English explanation of how FormForge works,
suitable for a non-technical HR manager who maintains form configurations.

Explain:
  - What the JSON file is and why editing it changes the form
  - What they can and cannot change without developer help
  - How they would add a new field or change a field label
  - Mention: they can now describe changes to Claude in plain English

Tone: approachable, non-patronizing. Avoid programming jargon.
```
