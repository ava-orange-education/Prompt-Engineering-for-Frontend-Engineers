# One-Shot: Named Entity Recognition

```
One-Shot: Named Entity Recognition

[EXAMPLE]
Text: 'Malala Yousafzai, co-founder of the Malala Fund, won the Nobel Peace Prize in Oslo in 2014.'

[MODEL]
Entities:
  PERSON: Malala Yousafzai
  ORGANIZATION: Malala Fund
  AWARD: Nobel Peace Prize
  LOCATION: Oslo
  DATE: 2014

[USER]
Text: 'Elon Musk founded SpaceX in El Segundo, California in 2002.'

[MODEL]
Entities:
  PERSON: Elon Musk
  ORGANIZATION:  SpaceX
  LOCATION: El Segundo, California
  DATE: 2002
```
