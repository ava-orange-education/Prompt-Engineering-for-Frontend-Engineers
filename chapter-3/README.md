# Chapter 3 — Prompt Engineering: Techniques, Patterns, and Practical Frameworks

Foundational chapter on prompt engineering for working with LLMs — naive prompting through
persona patterns, chain-of-thought, few-shot/zero-shot, tree-of-thought, and LLM-as-judge.

## What's in this folder
- `prompts/` — 17 worked prompt-pattern examples from the book, in the order they appear
  (naive prompting → personas → interview pattern → CoT → few-shot → tree-of-thought →
  LLM-as-judge → a production prompt template).

There's no code to build for this chapter — it's a reference library of prompt patterns you
can reuse when writing your own prompts (including the ones in Chapters 5, 7, and 9).
